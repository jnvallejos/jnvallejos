# Hi, I'm Javier 👋

Senior Software Engineer based in Buenos Aires. 22+ years shipping production code across backend, mobile, and AI integration.

## What I do

- Backend & full-stack — ASP.NET Core, C#, .NET 8/9, Node.js, REST API design
- Mobile — native iOS (Swift), native Android (Java/Kotlin), React Native, on-device CV/ML
- AI integration — Anthropic Claude API, OpenAI, MCP (Model Context Protocol), RAG pipelines
- Cloud & infra — AWS (Lambda, EC2, S3), Vercel, Supabase, Docker

## Currently building

PostFuel — AI-powered content platform. Sole developer. Next.js + TypeScript + Claude API + Supabase + Vercel. Live in production with paying users.

## How I work

- Test-driven where it matters, pragmatic where it doesn't
- Read the codebase before suggesting rewrites
- Clean commits, clear PR descriptions, no surprises
- Fluent in AI-augmented workflows (Claude Code, MCP) — but the code review is mine
